`reel` is a command for making terminal recordings. It runs [VHS](https://github.com/charmbracelet/vhs) tapes, records commands, drives programs for scripts and agents, and turns asciicast files into GIFs, videos, and stills. It doesn't need Go to use, a browser, or anything else to run, apart from ffmpeg for some formats.

```console
$ reel run demo.tape
demo.tape: wrote demo.gif
demo.tape: wrote demo.cast
```

## What it does

| You want to | Use | Guide |
| --- | --- | --- |
| Script a demo, and regenerate it when your program changes | `reel run` | [Make demos from tapes](/cli/tapes) |
| Test a program without writing code | `reel test` | [Test with tapes](/cli/test) |
| Record yourself using a program | `reel rec` | [Record your terminal](/cli/record) |
| Drive a program from a script, or let an agent use one | `reel session` | [Drive programs](/cli/sessions) |
| Change how a recording looks, or cut it | `reel export`, `still`, `cut` | [Edit existing recordings](/cli/edit-recordings) |
| Render a `script(1)` recording | `reel attach` | [Render script(1) recordings](/cli/record#render-script1-recordings) |

Run `reel <command> --help` for every flag. Commands that list things print a table on a terminal, and tab-separated rows without headers when piped. `--json` prints JSON.

## Installation

Download the binary for your platform from [the releases page](https://github.com/lrstanley/steep/releases). It's a single file, with nothing to install alongside it.

| Platform | File |
| --- | --- |
| Linux | `reel_linux_amd64`, `reel_linux_arm64` |
| macOS | `reel_darwin_arm64` (Apple silicon), `reel_darwin_amd64` (Intel) |
| Windows | `reel_windows_amd64.exe`, `reel_windows_arm64.exe` |

On Linux and macOS, make it executable and put it on your `PATH`, named `reel`:

```console
$ chmod +x reel_linux_amd64
$ sudo mv reel_linux_amd64 /usr/local/bin/reel
```

Each release has the SHA-256 of every file in `steep_checksums.txt`. To check the files you downloaded, run `sha256sum --check --ignore-missing steep_checksums.txt` in the same directory. The macOS binaries aren't signed, so if a browser downloaded one, macOS blocks it the first time it runs. `xattr -d com.apple.quarantine reel` lets it run.

Or, with Go:

```console
go install github.com/lrstanley/steep/cmd/reel@latest
```

Video and WebP formats need [ffmpeg](https://ffmpeg.org) on your `PATH`, and [the rest need nothing](/reel/formats). `reel run` and `reel test` need a shell, and tapes run in `bash` unless they say otherwise. Fonts are built in, so recordings look the same on any machine.
