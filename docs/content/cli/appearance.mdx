These flags change how a recording is drawn, and they work on `run`, `export`, `attach`, `rec`, and session exports. Since an export is a replay, you can try them on a `.cast` as many times as you like. Each of these previews was made by `reel export` on one recording.

## Chrome

```console
reel export in.cast -o out.png --chrome
reel export in.cast -o out.png --no-chrome
```

## Padding, margin, and corners

```console
reel export in.cast -o out.png --chrome --padding 24 --margin 24 --margin-fill "#0b150f" --radius 12
```

<Demo src="cli-padding.png" alt="The tea shop in a window with padding, a margin, and rounded corners" />

`--margin-fill` also takes a gradient: two or more colors, after an optional angle in degrees clockwise from up, as in CSS. Without an angle, it runs top to bottom.

```console
reel export in.cast -o out.png --chrome --padding 24 --margin 24 --margin-fill "160deg #4b5a63 #1f272c" --radius 12
```

<Demo src="cli-gradient.png" alt="The tea shop in a window on a gradient from slate gray to near black" />

## Drop shadow

`--shadow` draws a shadow behind the window, into the margin. It takes the order of CSS `box-shadow`: the x and y offsets in pixels, then an optional blur in pixels, then an optional `#RRGGBB` or `#RRGGBBAA` color, which is black at half opacity by default. `none` turns off a shadow a tape sets.

```console
reel export in.cast -o out.png --chrome --padding 24 --margin 64 --margin-fill "#dfe8d6" --radius 12 --shadow "0 18 48 #17301f80"
```

<Demo src="cli-shadow.png" alt="The tea shop in a window on a pale green margin, with a soft shadow beneath it" />

The shadow only shows in the margin, so give it one at least as wide as the blur and the offset together, or the image's edge cuts it off.

## Themes

`--theme` takes a name from [`reel themes`](/cli/commands/themes), in any case, a file of xterm.js theme JSON, or that JSON itself. Themes are the [bubbletint](https://github.com/lrstanley/bubbletint) catalog.

```console
reel run demo.tape --theme "Tokyo Night" -o out.png
```

<ThemeGrid />

A theme sets a program's ANSI colors and defaults. It doesn't change the 24-bit colors a program chose, or colors a recording already set. A tape's run sets them for you, so use `--theme` on `reel run` rather than on a later `reel export`. See [The recording's colors](/reel/rendering#the-recordings-colors).

## Fonts

| Flag | Sets |
| --- | --- |
| `--font FAMILY[,FAMILY...]` | The first installed family in the list |
| `--font-size PX` | The size, which sizes the image too |
| `--letter-spacing PX` | Extra space between letters |
| `--line-height X` | A multiple of the font's line height |

[`reel fonts`](/cli/commands/fonts) lists them.

## Terminal indicators

| Flag | Draws |
| --- | --- |
| `--[no-]scrollbar` | A scrollbar, if there's scrollback |
| `--[no-]prompt-marks` | A badge on a failed command's row, from OSC 133 |
| `--[no-]link-underline` | An underline on OSC 8 hyperlinks |
| `--[no-]bell` | A flash for the bell |

[Terminal indicators](/reel/rendering#terminal-indicators) shows them.

## Timing

| Flag | Sets |
| --- | --- |
| `--fps N` | The frame rate. The default is 20. |
| `--speed X` | Playback speed. 2 plays twice as fast. |
| `--title TEXT` | The recording's title, for the window bar, intro card, and asciicast header |
