These flags add effects to `run`, `export`, `attach`, `rec`, and session exports.

## Cards

```console
reel export in.cast -o out.webp --intro 1s --intro-line "The Tea Shop" --outro 1s --outro-line "Thanks"
```

<Demo src="cli-cards.webp" alt="A recording with a title card at each end" />

Without `--intro-line`, the intro shows the title. An outro needs a line. Both flags repeat, for more lines.

## Pauses

```console
reel export in.cast -o out.webp --pause --pause-at filter:typed
reel export in.cast -o out.webp --hold-last 2s
```

<Demo src="cli-pause.webp" alt="A recording with a pause at a mark and at the end, each showing a badge" />

`--pause` pauses for a second at the end, with a badge. `--pause-at MARK` does the same at a mark, and repeats. `--hold-last` holds the last frame, with no badge.

## The mouse

`--mouse` draws the pointer, clicks, and drags. A tape turns it on with `Set MouseOverlay true`, and `reel run --no-mouse` turns that off for a run.

```console
reel export in.cast -o out.webp --mouse
```

## Cutting

`--hide FROM,TO` cuts the window between two marks. It repeats, and either mark may be empty for the start or end.

```console
reel export in.cast -o out.webp --hide filter:start,filter:done
```

<Demo src="cli-hide.webp" alt="A recording with the filtering cut out" />

## Highlight

```console
reel export in.cast -o out.webp --highlight 're= Matcha.*0m ;dim=0.6;between=brew:start,brew:done'
```

<Demo src="cli-highlight.webp" alt="The screen dimmed except for one row, during a brew" />

## Zoom

```console
reel export in.cast -o out.webp --zoom 'cells=1,10,38,14;between=brew:start,brew:done'
```

<Demo src="cli-zoom.webp" alt="The view easing in on the status area during a brew" />

## Secrets

```console
reel export in.cast -o out.webp --redact-regexp 'tea-[0-9a-f]+'
reel export in.cast -o out.webp --redact-env GITHUB_TOKEN
reel export in.cast -o out.webp --redact 'env=GITHUB_TOKEN;style=blur'
```

<Demo src="cli-redact.webp" alt="The tea shop with its license key hidden" />

These can't be combined with a `.cast` output, which would keep the secret. And `.snap` and `.json` outputs skip effects. [Redact](/reel/redact#where-it-stops) has what it can't catch, so watch the result before sharing it.

## Spec

`--highlight`, `--zoom`, and `--redact` take a spec: `REGION[;KEY=VALUE]...`, and they repeat. [`reel s wait --idle`](/cli/sessions#waiting) takes a `REGION` on its own.

| Region | Covers |
| --- | --- |
| `row=Y` | One row, from 0 at the top, or from -1 at the bottom |
| `rows=Y0-Y1` | Rows from `Y0` up to `Y1`. After a negative `Y0`, a `Y1` of 0 is the bottom, so `rows=-2-0` is the last two rows |
| `cells=X0,Y0,X1,Y1` | A rectangle of cells |
| `text=TEXT` | Each place `TEXT` shows |
| `re=PATTERN` | Each match of a regular expression |
| `env=NAME` | Each place the value of a variable shows |

| Key | Effects | Is |
| --- | --- | --- |
| `between=FROM,TO` | All | The window between two marks. Either may be empty. |
| `ease=DUR` | Highlight, zoom | How long to ease in and out |
| `dim=FACTOR` | Highlight | How much to darken the rest, from 0 to 1 |
| `outline=#RRGGBB[:PX]` | Highlight | A border |
| `padding=PX` | Highlight | Undimmed pixels around the region |
| `scale=FACTOR` | Zoom | How many times larger |
| `anchor=X,Y` | Zoom | Where it sits, as a fraction of the grid |
| `style=blur\|block\|replace:C` | Redact | How it hides |

Values can't contain `;`, so neither can a region's text or pattern. Quote specs, since your shell cares about `;`.

## Captions

Captions are text for whoever watches: a **caption** is a pill at the top or bottom of the terminal, and a **callout** is a box with a caret pointing at cells of the screen. They're placed in the recording as it's made, from a tape or a [session](/cli/sessions), and every export draws them.

<Demo src="captions-demo.webp" alt="The shop with captions at the top and callouts pointing at what to press" cast="captions-demo.cast" />

In a tape, `Caption` shows a caption from that point, and `Callout` a callout, whose spec is a [region](#spec) and its options. Each shows until the next of its sort, or `EndCaption` or `EndCallout`:

```tape
Caption "The Tea Shop lists teas to filter and brew"
Callout "text=/ filter" "Press / to filter the menu"
Type "/"
Type "green"
EndCallout
Caption "Only the green teas are left" "for=2s"
Escape
Callout "text=Oolong;spotlight;pause=2s" "Press enter to brew it"
```

In a session, they're `reel s caption`, `reel s callout`, and `reel s end-caption`:

```console
reel s caption "Building the project" --options "pause=auto"
reel s callout "text=PASS;spotlight" "Every test passed"
reel s end-caption --callout
```

Both take these options, after a callout's region:

| Option | Does |
| --- | --- |
| `pause=DUR\|auto` | Pauses playback as it starts, for a reading time with `auto`. `pause=0s` is no pause, even with `--caption-pause`. |
| `for=DUR` | Ends it this long into the recording after it starts. `for=0s` shows it only while its pause lasts. |
| `until=MARK` | Ends it at the first mark labeled `MARK` |
| `side=top\|bottom\|left\|right` | Where it goes: `top` or `bottom` of the terminal for a caption, a side of its anchor for a callout. The default covers the least text. |
| `spotlight` | Darkens all but a callout's anchor while it shows |

Captions don't pause unless they say to. For a demo, `--caption-pause auto` (tape: `Set CaptionPause auto`) pauses at each caption that sets no pause of its own, for a reading time, or for a duration such as `2s`. `--caption-pause none` leaves out every pause, so a recording made as a demo plays at its own pace:

```console
reel export demo.cast -o demo.webp --caption-pause auto
reel export demo.cast -o fast.webp --caption-pause none
```

See [Captions](/reel/captions) for how they're laid out and timed.

## In a tape

Tapes take the same spec, as commands:

```tape
Highlight "re=ERROR.*;dim=0.5"
Zoom "cells=0,0,40,10"
Redact "env=GITHUB_TOKEN"
```

See [the effects themselves](/reel/effects) for what they do in detail.
